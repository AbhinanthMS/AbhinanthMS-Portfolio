# Personal Portfolio Website

A modern, responsive personal portfolio website built using pure HTML and CSS.

## 🚀 Overview

This portfolio website showcases my journey as a Computer Science Engineering student and aspiring Full Stack + AI Developer.

The website includes:

- Responsive navigation bar
- Hero/Home section
- About Me section
- Skills & Technologies section
- Projects showcase
- Contact section
- Mobile-friendly responsive design

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Font Awesome Icons

## ✨ Features

### Responsive Design
- Optimized for desktop, tablet, and mobile devices.
- Uses media queries for different screen sizes.

### Modern UI
- Dark theme with purple accent colors.
- Smooth hover animations and transitions.
- Glassmorphism-inspired navigation bar.

### Sections Included
- Home
- About
- Skills
- Projects
- Contact

### Skills Showcase
Displays learning progress in:
- HTML
- CSS
- JavaScript
- Python
- AI / Machine Learning

### Projects Section
Includes:
- Portfolio Website
- Split Calculator
- Upcoming Projects
